# agda-deans-problem v0.1.0

+  **Paper**: William DeMeo and Ralph Freese, *No free lattice contains an
   infinite ascending chain of copies of FL(3)*, to be posted on arXiv; its
   identifier is added in v0.1.1.
+  **Code**: the modules, `flake.nix` and `flake.lock` of commit
   [`9f195d3`], the merge of [#18] on 30 October 2026, at which the paper's
   Section 10 was measured.  The commits on top of it add the counts and
   the cost to the README, these notes, and the version to
   [`CITATION.cff`].
+  **Pins**: [agda-lattices][] at its release `v0.2.0` (commit `41fb55e4`);
   the [Agda Universal Algebra Library][agda-algebras] at commit `b4d0ab6c`;
   Agda 2.9.0, a pre-release built from agda/agda at commit `da66a8c7`; the
   Agda standard library 2.3, patched to check under it.
+  **License**: Apache-2.0 ([`LICENSE`]).

This is the first release of the formal development of the paper, and the
state of the repository that the paper cites.  The paper answers
R. A. Dean's question in the negative: no free lattice contains an infinite
strictly ascending chain of sublattices, each isomorphic to the free lattice
`FL(3)` on three generators.

## What it holds

+  **The paper's results**.  Each of its 48 results is one Agda definition
   whose type is its statement, with one proof, defined in the module that
   proves it and re-exported, in the paper's order, by
   [`DeansProblem.Paper`].  The README's [table of results][table] maps each
   result to its names and its module, and `make check` checks the table
   against `DeansProblem.Paper` and resolves every name in it.
+  **The main theorem**.  `Theorem-H`, in [`DeansProblem.NoChain`], says
   that the free lattice over a type of generators with decidable equality
   contains no infinite strictly ascending chain of sublattices isomorphic
   to `FL(3)`.  Decidable equality on the generators is its one hypothesis,
   and its proof uses no classical principle.
+  **Two results under a hypothesis**.  The coherent form of Theorem C and
   Corollary 6.4 take the infinite pigeonhole principle, which Agda's logic
   does not prove, as an explicit argument named in their types, never as a
   postulate.  The proof of Theorem H uses neither of them.
+  **The modules**.  38 modules of literate Agda under `src/`, 15,410 lines
   of source, of which 9,312 are Agda code; the check reads 39 modules of
   agda-lattices and 95 of the Agda Universal Algebra Library with them.
+  **The pragma**.  Every module carries
   `{-# OPTIONS --without-K --exact-split --safe #-}`, and none holds a
   postulate or a pragma that switches a check off; `make check` checks
   that before it runs Agda.

## Checking it

With Nix 2.28 or later, flakes enabled, the following checks the release:

    git clone https://github.com/ualib/agda-deans-problem.git
    cd agda-deans-problem
    git checkout v0.1.0
    nix develop --command make check

The archived copy of the tag checks the same way, from the directory it
unpacks to.  The check exits 0, and its last line is the following:

    check-paper: 48 results agree with DeansProblem.Paper; 207 names resolve in 40 modules

The README's [Checking it][checking] says how to fetch the pre-release Agda
from the public binary cache instead of building it, and what to write when
flakes are not enabled.  At a load average under 1.1, `make check` from
source took 37.7 seconds, 32.5 of them the Agda run, at a peak of 2.2 GiB
of memory; with the libraries' interfaces built, the Agda run took 15.0
seconds.  The README's [The cost][cost] gives the measurements, on a loaded
machine too, and the counts.

That the release's code is that of the commit the paper measured is one
command in a clone:

    git diff --quiet 9f195d3 v0.1.0 -- src flake.nix flake.lock && echo code-identical
