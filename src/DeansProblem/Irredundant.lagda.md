### Strongly irredundant intervals: Freese's Lemma 2

This is the [DeansProblem.Irredundant][] module of this repository.

Freese's "Notes on Dean's problem" (1997) end with an "almost proof" that a free
lattice has no infinite ascending chain of sublattices isomorphic to `FL(3)`, and
its last step is the following lemma.

**Lemma 2** (Freese).  Suppose `a⁻ ≤ a⁺`, `b⁻ ≤ b⁺`, and `c⁻ ≤ c⁺` are strongly
join and meet irredundant, that is, `a⁻ ≰ b⁺ ∨ c⁺` and symmetrically and dually.
If `a⁻ ≤ a ≤ a⁺` and similarly for `b` and `c`, then `a` is the only element of
the sublattice generated by `a`, `b`, and `c` in the interval `[a⁻, a⁺]`.

*Proof* (Freese's).  Suppose `a⁻ ≤ w` and `w` is in the sublattice generated by
`a`, `b`, and `c`.  Then either `w ≥ a` or `w ≤ b ∨ c`.  The latter gives
`a⁻ ≤ w ≤ b ∨ c ≤ b⁺ ∨ c⁺`, a contradiction.  So `w ≥ a`, and similarly
`w ≤ a`.  ∎

The lemma holds in any lattice, and nothing in it is about free lattices: the
generators need not be free, and the proof uses only the order.  This module
proves it in that generality.  The step "either `w ≥ a` or `w ≤ b ∨ c`" is a
*partition lemma* (`above-or-below`{.AgdaFunction}), proved by induction on the
term that names `w`: for any family `η` of elements, any index `i`, and any `r`
lying above every other member of the family, each element of the sublattice the
family generates lies above `η i` or below `r`.  A generator is `η i` itself or
another member, below `r`; a join is above `η i` as soon as one joinand is, and
below `r` when both are; a meet is above `η i` when both meetands are, and below
`r` as soon as one is.  Its dual (`below-or-above`{.AgdaFunction}) puts every
element below `η i` or above a lower bound `m` of the other members.  The two
together pin an element at one index (`pinned`{.AgdaFunction}), and Freese's
lemma reads them for three elements, one index at a time
(`lemma-2-at`{.AgdaFunction}) and at all three (`lemma-2`{.AgdaFunction}).

Read at a single index, the lemma needs only two of the six irredundance
conditions: `a` is pinned in `[a⁻, a⁺]` as soon as `a⁻ ≰ b⁺ ∨ c⁺` and
`b⁻ ∧ c⁻ ≰ a⁺`, the conditions *at* `a` (`IrredundantAt`{.AgdaFunction}).
[DeansProblem.AlmostProof][] uses that refinement.

#### The partition lemma

Fix a lattice `𝑳`{.AgdaBound}, with the meet order of `Lattice-Order`{.AgdaModule},
and a family `η` of its elements indexed by `I`.  The sublattice the family
generates is the set of values `⟦ t ⟧ η` of lattice terms `t` over `I`
(`Evaluation`{.AgdaModule} of [Lattices.Free.Term][]).  The hypothesis "every
other member lies below `r`" is stated without a decidable equality on `I`: for
each index `j`, either `j` is `i` or `η j ≤ r`.

```agda
module _ (𝑳 : Lattice α ρ) where
  open Lattice-Op 𝑳          using ( _∧_ ; _∨_ )
  open Lattice-Order 𝑳       using ( _≤_ ; ≤-refl ; ≤-trans ; ≤-antisym ; ∧-greatest ; ∧-lowerˡ
                                   ; ∧-lowerʳ ; ∨-least ; ∨-upperˡ ; ∨-upperʳ )
  open Setoid 𝔻[ proj₁ 𝑳 ]   using ( _≈_ )
  open Evaluation 𝑳          using ( ⟦_⟧ )

  private
    L : Type α
    L = 𝕌[ proj₁ 𝑳 ]

  module _ {I : Type ι} (η : I → L) (i : I) where

    -- Every element of the generated sublattice lies above η i or below r.
    above-or-below : {r : L} → (∀ j → j ≡ i ⊎ η j ≤ r)
                   → (t : LatTerm I) → η i ≤ ⟦ t ⟧ η ⊎ ⟦ t ⟧ η ≤ r
    above-or-below others≤r (ℊ j) with others≤r j
    ... | inj₁ refl  = inj₁ ≤-refl
    ... | inj₂ q     = inj₂ q
    above-or-below others≤r (s ∧̇ t)
      with above-or-below others≤r s | above-or-below others≤r t
    ... | inj₁ p | inj₁ q  = inj₁ (∧-greatest p q)
    ... | inj₂ p | _       = inj₂ (≤-trans ∧-lowerˡ p)
    ... | inj₁ _ | inj₂ q  = inj₂ (≤-trans ∧-lowerʳ q)
    above-or-below others≤r (s ∨̇ t)
      with above-or-below others≤r s | above-or-below others≤r t
    ... | inj₁ p | _       = inj₁ (≤-trans p ∨-upperˡ)
    ... | inj₂ _ | inj₁ q  = inj₁ (≤-trans q ∨-upperʳ)
    ... | inj₂ p | inj₂ q  = inj₂ (∨-least p q)

    -- Dually, every element lies below η i or above m.
    below-or-above : {m : L} → (∀ j → j ≡ i ⊎ m ≤ η j)
                   → (t : LatTerm I) → ⟦ t ⟧ η ≤ η i ⊎ m ≤ ⟦ t ⟧ η
    below-or-above m≤others (ℊ j) with m≤others j
    ... | inj₁ refl  = inj₁ ≤-refl
    ... | inj₂ q     = inj₂ q
    below-or-above m≤others (s ∧̇ t)
      with below-or-above m≤others s | below-or-above m≤others t
    ... | inj₁ p | _       = inj₁ (≤-trans ∧-lowerˡ p)
    ... | inj₂ _ | inj₁ q  = inj₁ (≤-trans ∧-lowerʳ q)
    ... | inj₂ p | inj₂ q  = inj₂ (∧-greatest p q)
    below-or-above m≤others (s ∨̇ t)
      with below-or-above m≤others s | below-or-above m≤others t
    ... | inj₁ p | inj₁ q  = inj₁ (∨-least p q)
    ... | inj₂ p | _       = inj₂ (≤-trans p ∨-upperˡ)
    ... | inj₁ _ | inj₂ q  = inj₂ (≤-trans q ∨-upperʳ)
```

An element of the sublattice above `lo` and below `hi` is `η i`, if `lo ≰ r` and
`m ≰ hi` (`pinned`{.AgdaFunction}): the partition puts it above `η i`, since
below `r` it would put `lo` below `r`; and its dual puts it below `η i`.

```agda
    -- An element of the sublattice in [lo, hi] is η i.
    pinned : {r m lo hi : L} → (∀ j → j ≡ i ⊎ η j ≤ r) → (∀ j → j ≡ i ⊎ m ≤ η j)
           → ¬ (lo ≤ r) → ¬ (m ≤ hi)
           → (t : LatTerm I) → lo ≤ ⟦ t ⟧ η → ⟦ t ⟧ η ≤ hi → ⟦ t ⟧ η ≈ η i
    pinned {r} {m} {lo} {hi} others≤r m≤others lo≰r m≰hi t lo≤ ≤hi =
      ≤-antisym (below (below-or-above m≤others t)) (above (above-or-below others≤r t))
      where
      above : η i ≤ ⟦ t ⟧ η ⊎ ⟦ t ⟧ η ≤ r → η i ≤ ⟦ t ⟧ η
      above (inj₁ p)  = p
      above (inj₂ q)  = ⊥-elim (lo≰r (≤-trans lo≤ q))

      below : ⟦ t ⟧ η ≤ η i ⊎ m ≤ ⟦ t ⟧ η → ⟦ t ⟧ η ≤ η i
      below (inj₁ p)  = p
      below (inj₂ q)  = ⊥-elim (m≰hi (≤-trans q ≤hi))
```

#### Three intervals

Freese states the lemma for three elements `a`, `b`, `c`, with "symmetrically"
meaning the cyclic permutation `a ↦ b ↦ c ↦ a` of his notes.  The two other
indices of an index of `Fin 3` are `other₁ i` and `other₂ i` of
[Lattices.Breadth][], in that cyclic order, and every index is `i` or one of its
two others (`others`{.AgdaFunction}).

Three intervals `[lo i, hi i]` are *irredundant at* `i`
(`IrredundantAt`{.AgdaFunction}) if `lo i ≰ hi j ∨ hi k` and
`lo j ∧ lo k ≰ hi i`, for the two others `j` and `k` of `i`; *strongly
irredundant* (`StronglyIrredundant`{.AgdaFunction}) if they are irredundant at
every index, which is Freese's hypothesis; and a family `η` lies in them
(`InIntervals`{.AgdaFunction}) if `lo i ≤ η i ≤ hi i` for each `i`.  Lemma 2 at
`i` (`lemma-2-at`{.AgdaFunction}) is `pinned`{.AgdaFunction} with `r = η j ∨ η k`
and `m = η j ∧ η k`: if `lo i ≤ η j ∨ η k`, then `lo i ≤ hi j ∨ hi k`, since the
family lies in the intervals; and dually.

```agda
module _ (𝑳 : Lattice α ρ) where
  open Lattice-Op 𝑳          using ( _∧_ ; _∨_ )
  open Lattice-Order 𝑳       using ( _≤_ ; ≤-trans ; ∧-greatest ; ∧-lowerˡ ; ∧-lowerʳ ; ∨-least
                                   ; ∨-upperˡ ; ∨-upperʳ )
  open Setoid 𝔻[ proj₁ 𝑳 ]   using ( _≈_ )
  open Evaluation 𝑳          using ( ⟦_⟧ )

  module _ (η lo hi : Fin 3 → 𝕌[ proj₁ 𝑳 ]) where

    -- Freese's conditions at one index, at all three, and the family in the intervals.
    IrredundantAt : Fin 3 → Type ρ
    IrredundantAt i = ¬ (lo i ≤ hi (other₁ i) ∨ hi (other₂ i))
                    × ¬ (lo (other₁ i) ∧ lo (other₂ i) ≤ hi i)

    StronglyIrredundant : Type ρ
    StronglyIrredundant = ∀ i → IrredundantAt i

    InIntervals : Type ρ
    InIntervals = ∀ i → lo i ≤ η i × η i ≤ hi i

    -- Lemma 2 at one index: η i is the only element of the sublattice in [lo i, hi i].
    lemma-2-at : (i : Fin 3) → IrredundantAt i → InIntervals
               → (t : LatTerm (Fin 3)) → lo i ≤ ⟦ t ⟧ η → ⟦ t ⟧ η ≤ hi i → ⟦ t ⟧ η ≈ η i
    lemma-2-at i (lo≰ , ≰hi) box =
      pinned 𝑳 η i others≤ ≤others (λ p → lo≰ (≤-trans p ∨-mono)) (λ p → ≰hi (≤-trans ∧-mono p))
      where
      others≤ : ∀ j → j ≡ i ⊎ η j ≤ η (other₁ i) ∨ η (other₂ i)
      others≤ j with others i j
      ... | inj₁ e                = inj₁ e
      ... | inj₂ (inj₁ refl)      = inj₂ ∨-upperˡ
      ... | inj₂ (inj₂ refl)      = inj₂ ∨-upperʳ

      ≤others : ∀ j → j ≡ i ⊎ η (other₁ i) ∧ η (other₂ i) ≤ η j
      ≤others j with others i j
      ... | inj₁ e                = inj₁ e
      ... | inj₂ (inj₁ refl)      = inj₂ ∧-lowerˡ
      ... | inj₂ (inj₂ refl)      = inj₂ ∧-lowerʳ

      ∨-mono : η (other₁ i) ∨ η (other₂ i) ≤ hi (other₁ i) ∨ hi (other₂ i)
      ∨-mono = ∨-least (≤-trans (proj₂ (box (other₁ i))) ∨-upperˡ)
                       (≤-trans (proj₂ (box (other₂ i))) ∨-upperʳ)

      ∧-mono : lo (other₁ i) ∧ lo (other₂ i) ≤ η (other₁ i) ∧ η (other₂ i)
      ∧-mono = ∧-greatest (≤-trans ∧-lowerˡ (proj₁ (box (other₁ i))))
                          (≤-trans ∧-lowerʳ (proj₁ (box (other₂ i))))

    -- Freese's Lemma 2.
    lemma-2 : StronglyIrredundant → InIntervals → (i : Fin 3)
            → (t : LatTerm (Fin 3)) → lo i ≤ ⟦ t ⟧ η → ⟦ t ⟧ η ≤ hi i → ⟦ t ⟧ η ≈ η i
    lemma-2 si box i = lemma-2-at i (si i) box
```
