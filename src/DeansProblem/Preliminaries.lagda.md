### The preliminaries: the results of Section 2

This is the [DeansProblem.Preliminaries][] module of this repository.

[the paper]: https://arxiv.org/abs/YYMM.NNNNN

Section 2 of [the paper][] collects what the paper uses from
[Freese, Ježek, and Nation (1995)][] (FJN below), and adds Theorem B and
Lemma 2.9.  This module states its eleven results, each as one definition
whose type is the paper's statement, and proves each from the statements of
FJN's results in [agda-lattices][], at the pinned release, which names them
by FJN's numbers (`FJN-1·8`{.AgdaFunction} for Theorem 1.8) or, for
Theorem 1.11, by its standard name (`WhitmansTheorem`{.AgdaRecord}); its
module [Lattices.Free.FJN][] lists them in the book's order.  A statement in
several parts is a record in `Setω` with one field per part, `part-1`,
`part-2`, ..., in the order the paper gives them, as the library states FJN's
results.

The free lattice `FL(X)` is `FL X`{.AgdaFunction}, whose elements are the
lattice terms over `X` under Whitman's equality `_≈ʷ_`{.AgdaFunction}, and a
homomorphism from `FL(I)` to `FL(X)` is a substitution `σ : Sub I X`, the
images of the generators (every homomorphism is one,
`hom-induced`{.AgdaFunction}); it is an embedding when it is injective, which
by Corollary 2.5 is when `σ` freely generates.  A lattice `L` is generated by
`η : X → L` when the homomorphism from `FL(X)` that extends `η` is onto.

Three hypotheses go beyond the paper's, each in the type and said here:

+  decidable equality on the generators, wherever a decision needs it: to
   decide the order (Theorem 2.3's sixth part), and to compute canonical
   forms and complexity (Theorems 2.6, 2.7 and B, Lemmas 2.8 and 2.9);
+  in Lemma 2.9, a finite set of generators is a type with a list of all its
   elements;
+  in Lemma 2.2 and Corollary 2.4, condition (†) is read for finite nonempty
   sets `S` and `T`, since with `S` empty and the empty meet read as the top
   it fails in `FL(X)` for finite nonempty `X`, whose top is `⋁X`; the
   library's `Satisfies†`{.AgdaFunction} says so.  This is a weaker
   hypothesis than the paper's as printed, so the statement is stronger.

#### Whitman's solution to the word problem

**Theorem 2.1** is FJN's Theorem 1.8 and the first part of its Corollary 1.9:
`FL(X)` satisfies Whitman's condition (W), and so does every lattice that
embeds in a free lattice, since (W) does not mention the generators.

```agda
-- Theorem 2.1: FL(X) satisfies (W), and so does every sublattice of a free lattice.
record Theorem-2·1 : Setω where
  field
    part-1 : ∀ {χ} {X : Type χ} → SatisfiesW (FL X)
    part-2 : ∀ {α ρ χ} (𝑲 : Lattice α ρ) {X : Type χ} → Embeds 𝑲 (FL X) → SatisfiesW 𝑲

-- The proof of Theorem 2.1.
theorem-2·1 : Theorem-2·1
theorem-2·1 = record { part-1 = fjn-1·8 ; part-2 = FJN-1·9.part-1 fjn-1·9 }
```

**Lemma 2.2** is FJN's Lemma 1.4 and Corollary 1.5, in a lattice `L`
generated by `η : X → L` with condition (†): every generator is join prime and
meet prime (part 3 of Lemma 1.4 at a single generator), and if `X` is the
disjoint union of `Y` and `Z`, then `L` is the disjoint union of the filter
generated by `Y` and the ideal generated by `Z` (its part 4).  Its
parenthetical, that (†) holds in `FL(X)`, is FJN's Lemma 1.2, and it is the
statement's first part.  A meet prime element is a join prime element of the
dual lattice.

```agda
-- Lemma 2.2: (†) holds in FL(X); under (†) the generators are join and meet prime,
-- and a partition of X partitions L into a filter and an ideal.
record Lemma-2·2 : Setω where
  field
    part-1 : ∀ {χ} {X : Type χ} → Satisfies† (FL X) ℊ
    part-2 : ∀ {α ρ χ} (𝓛 : Lattice α ρ) {X : Type χ} (η : X → 𝕌[ 𝓛 .proj₁ ])
             → IsSurjective (FL-extend 𝓛 η) → Satisfies† 𝓛 η
             → ∀ x → IsJoinPrime 𝓛 (η x) × IsJoinPrime (dualLattice 𝓛) (η x)
    part-3 : ∀ {α ρ χ ℓ₁ ℓ₂} (𝓛 : Lattice α ρ) {X : Type χ} (η : X → 𝕌[ 𝓛 .proj₁ ])
             → IsSurjective (FL-extend 𝓛 η) → Satisfies† 𝓛 η
             → (Y : Pred X ℓ₁) (Z : Pred X ℓ₂) → (∀ x → Y x ⊎ Z x) → (∀ {x} → Y x → Z x → ⊥)
             → ∀ b →  (GeneratedFilter 𝓛 η Y b ⊎ GeneratedIdeal 𝓛 η Z b)
                      × (GeneratedFilter 𝓛 η Y b → GeneratedIdeal 𝓛 η Z b → ⊥)

-- The proof of Lemma 2.2.
lemma-2·2 : Lemma-2·2
lemma-2·2 = record
  { part-1 = fjn-1·2
  ; part-2 = λ 𝓛 η onto dag x → FJN-1·4.part-3 fjn-1·4 𝓛 η onto dag x []
  ; part-3 = FJN-1·4.part-4 fjn-1·4
  }
```

**Theorem 2.3** is FJN's Theorem 1.11, Whitman's solution of the word
problem, which the library states as `WhitmansTheorem`{.AgdaRecord}: its
parts 1 to 6 are the six rules, as equivalences in the order of `FL(X)`; part
7 is the decision the rules give, with decidable equality on `X`; and part 8
says that this order is FJN's, `s ≤ t` holding in every lattice.

```agda
-- Theorem 2.3: Whitman's rules decide the order of FL(X).
Theorem-2·3 : Setω
Theorem-2·3 = WhitmansTheorem

-- The proof of Theorem 2.3.
theorem-2·3 : Theorem-2·3
theorem-2·3 = whitmans-theorem
```

#### Free generating sets

**Corollary 2.4** is FJN's Corollary 1.6, its first two parts, for `L`
generated by `η` with (†): every generating family `κ` of `L` contains each
generator `η x` (up to the equality of `L`), and every automorphism of `L` is
induced by a permutation of `X`.

```agda
-- Corollary 2.4: every generating set contains the generators, and every automorphism
-- is induced by a permutation of them.
record Corollary-2·4 : Setω where
  field
    part-1 : ∀ {α ρ χ ι} (𝓛 : Lattice α ρ) {X : Type χ} (η : X → 𝕌[ 𝓛 .proj₁ ])
             → IsSurjective (FL-extend 𝓛 η) → Satisfies† 𝓛 η
             → {J : Type ι} (κ : J → 𝕌[ 𝓛 .proj₁ ]) → IsSurjective (FL-extend 𝓛 κ)
             → let open Setoid 𝔻[ 𝓛 .proj₁ ] using ( _≈_ ) in
               ∀ x → Σ[ j ∈ J ] η x ≈ κ j
    part-2 : ∀ {α ρ χ} (𝓛 : Lattice α ρ) {X : Type χ} (η : X → 𝕌[ 𝓛 .proj₁ ])
             → IsSurjective (FL-extend 𝓛 η) → Satisfies† 𝓛 η
             → let open Setoid 𝔻[ 𝓛 .proj₁ ] using ( _≈_ ) in
               (φ : 𝓛 .proj₁ ≅ 𝓛 .proj₁)
             → Σ[ π ∈ X ↔ X ] (∀ x → _≅_.to φ .proj₁ ⟨$⟩ η x ≈ η (Inverse.to π x))

-- The proof of Corollary 2.4.
corollary-2·4 : Corollary-2·4
corollary-2·4 = record { part-1 = FJN-1·6.part-1 fjn-1·6 ; part-2 = FJN-1·6.part-2 fjn-1·6 }
```

**Corollary 2.5** is FJN's Corollary 1.13, read for a family `σ` of elements
of `FL(X)` indexed by `I`, as the paper reads it after the corollary: the
family satisfies the join condition and its dual (`FreelyGenerates σ`, the
conditions on lists of indices) exactly when the homomorphism from `FL(I)`
that it induces is injective, that is, when it generates a sublattice freely
generated by it.

```agda
-- Corollary 2.5: a family freely generates exactly when it satisfies the join condition
-- and its dual.
Corollary-2·5 : Setω
Corollary-2·5 =  ∀ {ι χ} {I : Type ι} {X : Type χ} (σ : Sub I X)
                 → FreelyGenerates σ ⇔ IsInjective (subst-hom σ .proj₁)

-- The proof of Corollary 2.5.
corollary-2·5 : Corollary-2·5
corollary-2·5 = fjn-1·13
```

#### Canonical form

**Theorem 2.6** is FJN's Theorems 1.17 and 1.18.  Canonical terms are the
library's `CTerm X`{.AgdaDatatype}, FJN's `n`-ary terms, and `LeastRank C`
says that `C` has the least rank among the terms naming its element.  Its
first part: every element `t` is named by a term of least rank, unique up to
commutativity (`_≈ᶜ_`{.AgdaFunction}).  Its second: a term is in canonical
form, the term of least rank, exactly when it satisfies the conditions of the
theorem, `IsCanonical`{.AgdaDatatype}, which says them for a join and dually
for a meet, and holds of every generator.

```agda
-- Theorem 2.6: each element has a term of least rank, unique up to commutativity, and a
-- term has least rank exactly when it satisfies the four conditions.
Theorem-2·6 : Setω
Theorem-2·6 =  ∀ {χ} {X : Type χ} → DecidableEquality X
               → ((t : LatTerm X) → Σ[ C ∈ CTerm X ] ⌊ C ⌋ ≈ʷ t × LeastRank C
                                    × (∀ D → ⌊ D ⌋ ≈ʷ t → LeastRank D → D ≈ᶜ C))
               × ((C : CTerm X) → IsCanonical C ⇔ LeastRank C)

-- The proof of Theorem 2.6.
theorem-2·6 : Theorem-2·6
theorem-2·6 _≟_ = fjn-1·17 _≟_ , fjn-1·18 _≟_
```

**Theorem 2.7** is the first sentence of FJN's Theorem 1.19: if `w` is also
the join `u ∨ u₁ ∨ ⋯` of a list, each canonical joinand of `w` lies below a
member of the list.  "Dually for meets" is not in FJN's statement, and the
library's `canonicalMeetands-refine`{.AgdaFunction} proves it.

```agda
-- Theorem 2.7: the canonical joinands refine every join representation, and dually.
Theorem-2·7 : Setω
Theorem-2·7 =  ∀ {χ} {X : Type χ} (_≟_ : DecidableEquality X)
               → (  {w u : LatTerm X} {us : List (LatTerm X)} → w ≈ʷ ⋁⁺ u us
                    → ∀ {c} → c ∈ canonicalJoinands _≟_ w → Any (c ≤ʷ_) (u ∷ us))
               × (  {w u : LatTerm X} {us : List (LatTerm X)} → w ≈ʷ ⋀⁺ u us
                    → ∀ {c} → c ∈ canonicalMeetands _≟_ w → Any (_≤ʷ c) (u ∷ us))

-- The proof of Theorem 2.7.
theorem-2·7 : Theorem-2·7
theorem-2·7 _≟_ = FJN-1·19.part-1 fjn-1·19 _≟_ , canonicalMeetands-refine _≟_
```

#### Embeddings and canonical joinands

**Lemma 2.8** is FJN's Lemma 9.13: an embedding of `FL(X)` in `FL(Y)` sends
a canonical joinand of `w` that is not a generator to a canonical joinand of
the image of `w`; and dually, by the library's
`embedding-canonicalMeetand`{.AgdaFunction}.

```agda
-- Lemma 2.8: an embedding sends a non-generator canonical joinand of w to a canonical
-- joinand of the image of w, and dually.
Lemma-2·8 : Setω
Lemma-2·8 =  ∀ {χ υ} {X : Type χ} {Y : Type υ}
             (_≟ˣ_ : DecidableEquality X) (_≟ʸ_ : DecidableEquality Y)
             (σ : Sub X Y) → IsInjective (subst-hom σ .proj₁) → (w : LatTerm X) {c : LatTerm X}
             → (c ∈ canonicalJoinands _≟ˣ_ w → (∀ x → ¬ (c ≈ʷ ℊ x))
                → Any (c [ σ ] ≈ʷ_) (canonicalJoinands _≟ʸ_ (w [ σ ])))
             × (c ∈ canonicalMeetands _≟ˣ_ w → (∀ x → ¬ (c ≈ʷ ℊ x))
                → Any (c [ σ ] ≈ʷ_) (canonicalMeetands _≟ʸ_ (w [ σ ])))

-- The proof of Lemma 2.8.
lemma-2·8 : Lemma-2·8
lemma-2·8 _≟ˣ_ _≟ʸ_ σ inj w =
  fjn-9·13 _≟ˣ_ _≟ʸ_ σ inj w , embedding-canonicalMeetand _≟ˣ_ _≟ʸ_ σ inj w
```

#### Complexity under embeddings

**Theorem B**: an embedding of `FL(X)` in `FL(Y)` never lowers complexity,
the depth of the canonical form (`complexity`{.AgdaFunction}).

```agda
-- Theorem B: a lattice embedding never lowers complexity.
Theorem-B : Setω
Theorem-B =  ∀ {χ υ} {X : Type χ} {Y : Type υ}
             (_≟ˣ_ : DecidableEquality X) (_≟ʸ_ : DecidableEquality Y)
             (σ : Sub X Y) → IsInjective (subst-hom σ .proj₁)
             → (w : LatTerm X) → complexity _≟ˣ_ w ≤ complexity _≟ʸ_ (w [ σ ])

-- The proof of Theorem B.
theorem-B : Theorem-B
theorem-B _≟ˣ_ _≟ʸ_ σ inj = complexity-mono _≟ˣ_ _≟ʸ_ σ inj
```

**Lemma 2.9**, for `X` listed by `enum`: for every `n` there is a finite list
of elements to which every element of complexity at most `n` is equal; hence
an infinite sequence of elements of bounded complexity takes some value
twice, and so does an infinite sequence of `m`-tuples.  The list is the
library's `bounded n`{.AgdaFunction} of the module `Bounded`{.AgdaModule},
the generators with the joins and the meets of the nonempty sublists of the
list one level down.

```agda
-- Lemma 2.9: finitely many elements of bounded complexity, and the pigeonhole for
-- sequences of elements and of tuples.
Lemma-2·9 : Setω
Lemma-2·9 =  ∀ {χ} {X : Type χ} (_≟_ : DecidableEquality X) (enum : List X) → (∀ x → x ∈ enum)
             → (∀ n → Σ[ L ∈ List (LatTerm X) ] (∀ w → complexity _≟_ w ≤ n → Any (w ≈ʷ_) L))
             × (∀ n (u : ℕ → LatTerm X) → (∀ k → complexity _≟_ (u k) ≤ n)
                → Σ[ i ∈ ℕ ] Σ[ j ∈ ℕ ] i < j × u i ≈ʷ u j)
             × (∀ n m (u : ℕ → Fin m → LatTerm X) → (∀ k l → complexity _≟_ (u k l) ≤ n)
                → Σ[ i ∈ ℕ ] Σ[ j ∈ ℕ ] i < j × (∀ l → u i l ≈ʷ u j l))

-- The proof of Lemma 2.9.
lemma-2·9 : Lemma-2·9
lemma-2·9 _≟_ enum complete =
    (λ n → bounded n , bounded-complete n)
  , (λ n u b → pigeonhole-≈ (bounded n) u (λ k → bounded-complete n (u k) (b k)))
  , (λ n m u b → pigeonhole-≈ⁿ (bounded n) m u (λ k l → bounded-complete n (u k l) (b k l)))
  where open Bounded _≟_ enum complete using ( bounded ; bounded-complete )
```
